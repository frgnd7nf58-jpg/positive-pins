Keep this address away from the builder

The child-facing pages contain no next/previous-day links and use unguessable addresses. A static site cannot enforce real access control, and anyone who can inspect a public repository can find the files. Treat this as protection from accidental peeking, not as a password system.

Recommended setup order

  1. Add the supplied advent folder to the root of the existing positive-pins repository. Do not replace its current index.html or messages.js.
  2. Open this parent guide at https://frgnd7nf58-jpg.github.io/positive-pins/advent/parent-sleigh-2c8v/.
  3. Open Create & print QR cards. Confirm the detected base address, generate the cards, and test at least Days 1, 12 and 24 with the phone that will be used.
  4. Print at 100% scale, colour or black-and-white, two A4 pages. Cut along the dashed outlines.
  5. Use the packing map and the part callouts in each day’s images to fill one envelope at a time.

Exact-part limitation

This plan verifies complete, ordered instruction ranges and ends only between numbered steps. It does not claim an exact machine-checked element inventory for each envelope. LEGO’s PDFs show parts inside each step callout, but they do not provide a dependable per-step data table. Pull the pieces shown in every callout for that day, place them in a tray, and dry-run the day before sealing the envelope.

Sorting method that avoids mistakes

  1. Keep each original numbered bag in its own shallow tray or food container. Never mix bags 1-6 together.
  2. For one day only, open its hidden page on a tablet or computer and place every callout piece into that day’s envelope.
  3. Tick the PDF page range on the packing map. If a day crosses a bag boundary, keep the two source bags physically separate.
  4. Keep the 41371 sticker sheet in an adult-only supply wallet. Apply stickers yourself when the instruction image requests one, or pass over only the sheet for that moment.
  5. Set aside large plates, animals and figure parts that were packed loose rather than inside a numbered bag.
  6. Dry-run at least the first page and last page of each day before sealing. For maximum certainty, build the day once, then carefully dismantle only that day’s new pieces into its envelope.

41039 figures and animals

Book 1 PDF page 3 reveals the full character and animal group, so it is deliberately absent from every child page. Use it only as an adult reference. The map suggests optional reveal days (3, 7, 12, 16, 20 and 23), but the exact character/animal distribution is a creative choice rather than something safely derived from numbered build steps.

Add it to the existing Positive Pins page

  1. Open the positive-pins repository in GitHub Desktop (or clone it with Git).
  2. Copy the complete supplied advent folder into the repository root, beside the existing index.html and messages.js.
  3. Commit with a message such as Add private-link Advent instructions, then push to main.
  4. Wait a minute or two, then open https://frgnd7nf58-jpg.github.io/positive-pins/advent/.
  5. Open the parent QR page, test Days 1, 12 and 24, and only then print the cards.

Privacy note: the existing repository and Pages site are public. The daily links are deliberately hard to guess and absent from the homepage, but anyone inspecting the public repository can find them. Share only the QR cards and remove the advent folder after Advent if desired.

Same-Wi-Fi local option

This keeps the manual images inside your home network, but the computer must remain on and the phone must use the same Wi-Fi.

  1. Install Python if it is not already available.
  2. Open a terminal in this project folder and run py -m http.server 8000 --bind 0.0.0.0 --directory dist.
  3. Find the computer’s local IPv4 address, for example 192.168.1.42.
  4. On the phone, open http://192.168.1.42:8000/. If Windows asks, allow access on private networks only.
  5. Open the parent QR page and replace its base address with the same phone-reachable address before printing.
